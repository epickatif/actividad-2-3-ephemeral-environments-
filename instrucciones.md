**Actividad 2.3. Ephemeral enviroments**

Utilizarás herramientas para la generación de ambientes efímeros para pruebas.

Los ambientes efímeros son entornos que se encuentran destinados a durar solo por un tiempo limitado (de allí su nombre). En esta actividad, desarrollarás uno que pueda ser utilizado en un proyecto simple y las pruebas que de él se realizarán.

1. Revisa los siguientes recursos:

What is an ephemeral environment?: https://webapp.io/blog/what-is-an-ephemeral-environment/

What is an Ephemeral Environment?: https://releasehub.com/ephemeral-environments

Getting Started on Heroku with Node.js: https://devcenter.heroku.com/articles/getting-started-with-nodejs#set-up

2. Crea una cuenta en Heroku.

3. Configura un repositorio con un proyecto simple de GitHub para hacer un despliegue (Deployment).

4. En un documento de Word, coloca el enlace a tu aplicación, y adjunta una breve descripción del proceso y de la aplicación.

5. Sube tu documento a este buzón de tarea.

Fondo

- Se describe de manera clara y precisa el proceso y aplicación de ambientes efímeros para pruebas.
- La aplicación cumple con todos los aspectos solicitados.
